# 蒼頡檢字法擴展計劃

## 緣由

[蒼頡檢字法《內碼對照表》文本化計劃](https://github.com/InSb/Cangjie6-Sharp)雖已完成，但由於官方編碼中疑似考慮不周的情況經常出現，文本化計劃提供的碼表在實際運用中多有不便。在此希望先以蒼頡內碼為基礎，追加更符合現有最優解釋的蒼頡全碼。

## 文件形式

### cangjie6_sharp_errata.tsv

該文件旨在以官方採用字形為準，用官方內碼索引，勘誤對應的全碼。修正時以官方內碼代表的字形為主要參考，輔以Unicode現行字形。

需注意保證官方內碼的唯一性：本文件內，蒼頡檢字法官方內碼不可重複。

和文本化計劃的`cangjie6_sharp.tsv`相同，採用以TAB分隔的表格。具體形式如下：

| 蒼頡檢字法官方內碼 | 蒼頡檢字法全碼（修正後） |
| :---: | :---: |
